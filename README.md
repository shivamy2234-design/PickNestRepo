# PickNest – E-Commerce Web Application

PickNest is an e-commerce web application developed using ASP.NET Core MVC. It is designed to provide a simple and user-friendly platform for browsing and managing products.

## Tech Stack

- **Backend:** C#, ASP.NET Core MVC
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Tools:** Visual Studio, Git, GitHub

## Features

- Product listing and management
- Product CRUD operations
- Product image upload
- Search functionality
- Sorting and pagination
- SQL Server database integration
- Entity Framework Core integration

## Project Structure

- `Controllers` – Handles application requests and business logic
- `Models` – Contains application data models
- `Data` – Database context and related files
- `Migrations` – Entity Framework Core migrations
- `Views` – Razor views and UI pages
- `wwwroot` – Static files such as CSS, JavaScript and images

## Getting Started

1. Clone this repository.
2. Open the project in Visual Studio.
3. Update the connection string named `constr` in your development configuration.
4. Apply Entity Framework Core migrations if required.
5. Run the application.
